# Newton's Second Law Lab

An interactive physics simulation by **Dr. M. Waseem** for exploring Newton's second law on an inclined plane.

## Features

- With-pulley and without-pulley modes
- Adjustable incline angle, masses, friction and gravity
- Animated motion of the block and hanging mass
- Force vectors and free-body diagrams
- Live force, acceleration and equation calculations
